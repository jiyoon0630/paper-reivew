# About

This is a personal archive of academic papers I study, written up as I read
them together with Claude. Each entry is a self-contained note: the core idea,
the method, the results that matter, and my own takeaways.

Papers are listed **newest first** on the [home page]({{ '/' | relative_url }}),
and each one is labelled with **tags** (e.g. `VLA`, `RL`) you can click to filter
the list.

## How entries are organized

- One paper = one Markdown file in `_posts/`.
- Filenames follow `YYYY-MM-DD-short-title.md`; the date drives the ordering.
- Math is written in LaTeX (`$...$` inline, `$$...$$` display) and rendered with MathJax.
